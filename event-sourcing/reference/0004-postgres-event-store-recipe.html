Postgres Event Store Recipe

Compressed from Lesson 04•Print-friendly

DDL

CREATE TABLE events (
    global_position  BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    event_id         UUID        NOT NULL UNIQUE,
    stream_id        TEXT        NOT NULL,
    stream_version   BIGINT      NOT NULL,
    event_type       TEXT        NOT NULL,
    schema_version   INT         NOT NULL DEFAULT 1,
    data             JSONB       NOT NULL,
    metadata         JSONB       NOT NULL DEFAULT '{}',
    occurred_at      TIMESTAMPTZ NOT NULL,
    recorded_at      TIMESTAMPTZ NOT NULL DEFAULT now(),
    tx_id            XID8        NOT NULL DEFAULT pg_current_xact_id(),
    CONSTRAINT uq_stream_version UNIQUE (stream_id, stream_version)   -- = OCC (+ its index)
);

REVOKE UPDATE, DELETE, TRUNCATE ON events FROM app_user;   -- immutable
GRANT  SELECT, INSERT           ON events TO   app_user;

Append (one tx, versions expected+1…)

INSERT INTO events (event_id, stream_id, stream_version, event_type, schema_version,
                    data, metadata, occurred_at)
VALUES (?, ?, ?, ?, ?, ?::jsonb, ?::jsonb, ?);      -- batch, then COMMIT

readStream / readAll

-- rehydrate one aggregate

-- feed projections (naive; see Lesson 08 for the gap-safe version using tx_id)
SELECT * FROM events WHERE global_position > ? ORDER BY global_position LIMIT ?;

Gotchas

Retry the whole load→decide→append, never just the insert. Client If-Match conflicts → 412, no auto-retry. global_position has gaps and commit-order surprises — don’t checkpoint naively (Lesson 08). Stream id = {type}-{id}; avoid unbounded streams.
