Erasure checklist (own the data map)

  • Destroy key / delete stream; append PII-free CustomerDataErased.
  • Read models scrub on that event; rebuild yields [erased].
  • Snapshots: no PII in aggregate state; delete subject’s snapshots.
  • Kafka: ids/ciphertext only; tombstone compacted keys; retention < deadline.
  • Backups & key-store backups / KMS soft-delete: retention < deadline (1 month default).
  • Data lake, logs, DLQ, search, caches: erasure handler or TTL each.
  • No PII in stream ids, metadata, tags or message keys.
