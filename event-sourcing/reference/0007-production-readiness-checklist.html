Event Sourcing · Reference 07

Production Readiness Checklist

Compressed from Lessons 07 & 08•Print-friendly

Snapshots

  • A cache, never truth: truncate snapshots and everything still works.
  • Added only after measuring rehydration p99.
  • schema_version checked on load; mismatch → full replay.
  • Written asynchronously every N events; upsert only if newer.
  • Long streams? First look for a lifecycle to close the books on.

Stream lifecycle

  • Natural period identified (day, shift, billing cycle, term) → …Closed / …Opened carrying state forward.
  • Opening the next stream is idempotent (expected version = no stream).
  • Closed streams archived to object storage and still replayable.
  • Hot aggregates: shard, commutative events with expectedVersion=Any, or queue.

Subscriptions

  • One active instance per projection/partition (advisory lock on a dedicated connection, K8s Lease, ShedLock).
  • Lost leadership connection ⇒ stop processing immediately.
  • LISTEN/NOTIFY is a wake-up hint; always poll as well.
  • Retries with backoff → park poison events → alert.

SELECT * FROM events
 WHERE (tx_id, global_position) > (:ckpt_tx, :ckpt_pos)
   AND tx_id < pg_snapshot_xmin(pg_current_snapshot())
 ORDER BY tx_id, global_position LIMIT 500;
