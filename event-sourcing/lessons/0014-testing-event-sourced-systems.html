Event Sourcing · Lesson 14

Testing Event-Sourced Systems

◷ ~15 min read • Level 4 · Advanced • Prereq: Lesson 13 · GDPR & temporal queries

Event sourcing has the best unit-testing story in software — Given past events, When a command, Then new events or an error. No mocks, no database, no Spring context. But the bugs that page you at 3 a.m. live elsewhere: duplicate delivery, concurrent appends, the gap problem, a field rename that breaks a six-year-old event. This lesson builds the full test pyramid, layer by layer, in Java 21.

2. Decider tests: a tiny Given/When/Then DSL

Twenty lines of test DSL make every business rule a three-line specification that a domain expert can read. The clock is fixed, so decide is deterministic.

class AccountTest {

    private final Clock clock = Clock.fixed(Instant.parse("2026-01-01T10:00:00Z"), ZoneOffset.UTC);
    private final Instant t = clock.instant();

    @Test
    void withdraw_within_balance_emits_MoneyWithdrawn() {
        given(new AccountOpened("A1", "u1", "EUR", t),
              new MoneyDeposited("A1", new BigDecimal("100"), t))
        .when(new Withdraw("A1", new BigDecimal("30")))
        .then(new MoneyWithdrawn("A1", new BigDecimal("30"), t));
    }

    @Test
    void withdraw_beyond_balance_is_rejected() {
        given(new AccountOpened("A1", "u1", "EUR", t),
              new MoneyDeposited("A1", new BigDecimal("10"), t))
        .when(new Withdraw("A1", new BigDecimal("30")))
        .thenThrows(DomainException.class, "Insufficient funds");
    }

    // --- tiny DSL ---
    private Scenario given(AccountEvent... history) { return new Scenario(List.of(history)); }

    private final class Scenario {
        private final List<AccountEvent> history;
        private AccountCommand cmd;
        Scenario(List<AccountEvent> h) { history = h; }
        Scenario when(AccountCommand c) { cmd = c; return this; }
        void then(AccountEvent... expected) {
            assertEquals(List.of(expected), Account.decide(cmd, Account.rehydrate(history), clock));
        }
        void thenThrows(Class<? extends Throwable> type, String msg) {
            var ex = assertThrows(type, () -> Account.decide(cmd, Account.rehydrate(history), clock));
            assertEquals(msg, ex.getMessage());
        }
    }
}
Assert on events, never on state

The Then is the emitted events, not the aggregate’s private state. Events are the public contract; state is an implementation detail you’re free to reshape. Tests that assert state break on every refactor and miss the bug that matters: emitting the wrong fact. Also add “Then nothing” tests (then() with no events) for idempotent commands.

3. Property-based tests with jqwik

Example tests check cases you thought of. Properties check rules against hundreds of generated sequences — and jqwik shrinks a failure to the smallest sequence that reproduces it.

class AccountProperties {

    private final Clock clock = Clock.fixed(Instant.parse("2026-01-01T10:00:00Z"), ZoneOffset.UTC);

    // Invariant holds for ANY sequence of commands; rejected commands are simply skipped.
    @Property(tries = 1000)
    void balance_never_negative(@ForAll("commandSequences") List<AccountCommand> cmds) {
        AccountState s = Account.INITIAL;
        for (var c : cmds) {
            try { for (var e : Account.decide(c, s, clock)) s = Account.evolve(s, e); }  // evolve must not throw
            catch (DomainException ignored) { }
        }
        if (s instanceof AccountState.Open o) assertTrue(o.balance().signum() >= 0);
    }

    // Rehydrating from the full history equals incremental application.
    @Property
    void rehydrate_equals_incremental(@ForAll("commandSequences") List<AccountCommand> cmds) {
        AccountState s = Account.INITIAL;
        var history = new ArrayList<AccountEvent>();
        for (var c : cmds) {
            try {
                var events = Account.decide(c, s, clock);
                history.addAll(events);
                for (var e : events) s = Account.evolve(s, e);
            } catch (DomainException ignored) { }
        }
        assertEquals(s, Account.rehydrate(history));
    }

    @Provide
    Arbitrary<List<AccountCommand>> commandSequences() {
        Arbitrary<BigDecimal> amounts = Arbitraries.bigDecimals()
                .between(new BigDecimal("0.01"), new BigDecimal("1000")).ofScale(2);
        Arbitrary<AccountCommand> cmd = Arbitraries.oneOf(
                Arbitraries.just(new OpenAccount("A1", "u1", "EUR")),
                amounts.map(a -> new Deposit("A1", a)),
                amounts.map(a -> new Withdraw("A1", a)),
                Arbitraries.just(new CloseAccount("A1", "customer request")));
        return cmd.list().ofMinSize(1).ofMaxSize(60);
    }
}

Subscriptions deliver at least once. A projection that isn’t idempotent will double-count the first time a consumer restarts between writing rows and saving its checkpoint. Play with the failure first:

@Testcontainers
class StatementProjectionIT {

    @Container
    static final PostgreSQLContainer<?> PG = new PostgreSQLContainer<>("postgres:16-alpine");

    static DataSource ds;
    StatementProjection projection;
    final Instant t = Instant.parse("2026-01-01T10:00:00Z");

    @BeforeAll static void migrate() { ds = dataSource(PG); Flyway.configure().dataSource(ds).load().migrate(); }
    @BeforeEach void setUp() { truncate(ds, "statement_line", "checkpoints"); projection = new StatementProjection(ds); }

    @Test
    void projects_deposit_into_statement_line() {
        projection.handle(List.of(envelope(1, new MoneyDeposited("A1", new BigDecimal("100"), t))));
        assertEquals(new BigDecimal("100.00"), balanceOf("A1"));
        assertEquals(1L, checkpoint("statement"));
    }

    @Test
    void duplicate_delivery_is_idempotent() {
        var batch = List.of(envelope(1, new MoneyDeposited("A1", new BigDecimal("100"), t)),
                            envelope(2, new MoneyWithdrawn("A1", new BigDecimal("30"), t)));
        projection.handle(batch);
        projection.handle(batch);                      // redelivery after a crash
        projection.handle(List.of(batch.get(1)));      // partial redelivery
        assertEquals(new BigDecimal("70.00"), balanceOf("A1"));
        assertEquals(2, countRows("statement_line"));
        assertEquals(2L, checkpoint("statement"));
    }

    @Test
    void rebuild_from_scratch_equals_incremental() {
        var all = sampleHistory(500);
        all.forEach(e -> projection.handle(List.of(e)));
        var incremental = dump("statement_line");
        truncate(ds, "statement_line", "checkpoints");
        projection.handle(all);
        assertEquals(incremental, dump("statement_line"));
    }
}
Don’t test projections with H2

ON CONFLICT, JSONB, xid8, advisory locks and transaction visibility are exactly the behaviours under test. An in-memory lookalike passes the tests and fails in production. Use the real engine; Testcontainers makes it a few seconds per class (reuse a static container across methods).

5. Event-store contract tests

Write the store’s guarantees once as an abstract test class; run it against every implementation (in-memory fake for fast decider integration tests, Postgres for real). If the fake passes the same contract, you can trust it elsewhere.

abstract class EventStoreContract {

    protected abstract EventStore store();

    @Test
    void appends_are_read_back_in_stream_order() {
        store().append("acc-1", 0, List.of(opened(), deposit(10), deposit(20)));
        assertEquals(List.of(1L, 2L, 3L),
                store().readStream("acc-1", 0).stream().map(EventEnvelope::streamVersion).toList());
    }

    @Test
    void stale_expected_version_is_rejected() {
        store().append("acc-1", 0, List.of(opened()));
        assertThrows(ConcurrencyException.class, () -> store().append("acc-1", 0, List.of(deposit(5))));
    }

    @RepeatedTest(20)
    void exactly_one_of_two_concurrent_writers_wins() throws Exception {
        var stream = "acc-" + UUID.randomUUID();
        store().append(stream, 0, List.of(opened()));
        var start = new CountDownLatch(1);
        Callable<Boolean> writer = () -> {
            start.await();
            try { store().append(stream, 1, List.of(deposit(1))); return true; }
            catch (ConcurrencyException e) { return false; }
        };
        try (var pool = Executors.newFixedThreadPool(2)) {          // ExecutorService is AutoCloseable (Java 19+)
            var a = pool.submit(writer);
            var b = pool.submit(writer);
            start.countDown();
            assertEquals(1, Stream.of(a.get(), b.get()).filter(won -> won).count());
        }
        assertEquals(2, store().readStream(stream, 0).size());
    }

    @Test
    void global_reader_never_skips_a_slow_commit() throws Exception {
        try (var slow = beginTransaction()) {                 // holds position N open, uncommitted
            slow.append("acc-slow", 0, List.of(opened()));
            store().append("acc-fast", 0, List.of(opened()));  // N+1 commits first
            var seen = store().readAll(0, 100);
            assertTrue(seen.stream().noneMatch(e -> e.streamId().equals("acc-fast")),
                    "reader must not move past an in-flight lower position");
            slow.commit();
        }
        assertEquals(List.of("acc-slow", "acc-fast"),
                store().readAll(0, 100).stream().map(EventEnvelope::streamId).toList());
    }
}

class PostgresEventStoreIT extends EventStoreContract { /* @Container PG, return new PostgresEventStore(ds) */ }
class InMemoryEventStoreTest extends EventStoreContract { /* return new InMemoryEventStore() */ }

The last test is the gap problem from Lesson 08 turned into a regression test: it fails on a naive WHERE global_position > ? reader and passes with the tx_id visibility filter. (beginTransaction() is a test hook that is a no-op for the in-memory store, where the property holds trivially.)

6. Schema compatibility: the golden-file corpus

Every event type and schema version that has ever reached production gets a JSON sample checked into the repo. The corpus is append-only: you add files, never edit or delete them. Every build must deserialise and upcast all of them.

src/test/resources/event-corpus/
  MoneyDeposited/v1/amount-as-number.json
  MoneyDeposited/v1/amount-as-number.expected.json   // what v-latest should look like
  MoneyDeposited/v2/amount-as-object.json
  AccountOpened/v1/basic.json
class EventCorpusTest {

    private final ObjectMapper json = new ObjectMapper();
    private final EventSerde serde = EventSerde.withUpcasters(Upcasters.all());

    @ParameterizedTest(name = "{0}")
    @MethodSource("corpus")
    void historical_event_still_deserialises_and_upcasts(Path file) throws IOException {
        var raw = RawEvent.fromCorpusFile(file);                // type + schema_version from path
        var event = assertDoesNotThrow(() -> serde.deserialize(raw));
        var expected = file.resolveSibling(file.getFileName().toString().replace(".json", ".expected.json"));
        if (Files.exists(expected)) {
            assertEquals(json.readTree(expected.toFile()), json.valueToTree(event));
        }
    }

    static Stream<Path> corpus() throws IOException {
        return Files.walk(Path.of("src/test/resources/event-corpus"))
                .filter(p -> p.toString().endsWith(".json") && !p.toString().endsWith(".expected.json"));
    }
}
Make the corpus self-maintaining

Add a CI check that every event_type/schema_version pair seen in production (a nightly SELECT DISTINCT exported as a manifest) has at least one corpus file, and that no corpus file was modified (checksum manifest). This turns “we forgot the upcaster” from a production incident into a red build.

7. Replay tests on anonymised production data

  • Anonymise first. If you crypto-shred (Lesson 13), copying the events without the key store gives you a PII-free dataset for free. Otherwise run a scrubbing job — never replay raw prod PII in CI.
  • Diff, don’t assert. Row-level diff of every read model between release N and N+1. Unexpected diffs block the release; intended ones are listed in the PR description.
  • Time it. The replay is also your rebuild-duration benchmark: if the largest projection now takes 9 hours instead of 2, you learn it here, not during an incident.
  • Catch poison events. Any event that throws during replay is a bug in evolve, an upcaster, or a projection — found before it parks a production subscription.
