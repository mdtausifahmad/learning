# Notes & Preferences

## Learner profile
- **Senior** engineer targeting **Staff**. Part of the broader plan in `../README.md` and
  `../02-skills-to-upgrade.md`.
- Comfortable with CRUD services, REST and relational DBs. Event sourcing starts from **level zero**.

## Teaching preferences
- Visual and interactive: HTML lessons with step-through animations, **live simulators**
  (`assets/es-sim.js`) and quizzes, in the same Tufte format as `../Observability` and `../async-messaging`.
- `GUIDE.md` is the long-form markdown edition with Mermaid diagrams. Use it for reading end to end
  or for search.
- Ground every example in **Java 21 + PostgreSQL + Kafka**. Show real, runnable code over pseudo-code.
- Every lesson ends with **staff-level judgement**: trade-offs, failure modes and what to ask in a review.

## Conventions
- Course identity colour: **indigo** (#4b3f8f). Siblings use teal (Observability) and brick (async-messaging).
- Quizzes: 4 options of similar length, per-option feedback, explanation after answering.
- Lab: `assets/lab/`, Postgres only, run with `podman compose`.
