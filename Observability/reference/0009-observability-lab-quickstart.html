The pipeline

your app --OTLP--> OTel Collector --> Prometheus (metrics) --> Grafana
                                  \--> Jaeger (traces)

Run it

TrackCommands

cd opentelemetry-demo && docker compose up -d
B · your svc
(the real skill)		cd assets/lab && docker compose up -d

URLs

Prometheus (PromQL):9090 (demo: :8080/…)
Grafana (dashboards):3000 (demo: :8080/grafana/)
Jaeger (traces):16686 (demo: :8080/jaeger/ui/)

Instrument your service (zero-code)

export OTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:4318
export OTEL_SERVICE_NAME=my-service

# Python:  opentelemetry-instrument python app.py
# Node:    node --require @opentelemetry/auto-instrumentations-node/register app.js
# Java:    java -javaagent:opentelemetry-javaagent.jar -jar app.jar

Golden-signal PromQL

# Traffic
sum(rate(http_server_request_duration_seconds_count[5m]))
# Errors (5xx ratio)
sum(rate(http_server_request_duration_seconds_count{http_response_status_code=~"5.."}[5m]))
  / sum(rate(http_server_request_duration_seconds_count[5m]))
# Latency p95
histogram_quantile(0.95, sum by (le) (rate(http_server_request_duration_seconds_bucket[5m])))

Metric names vary by library — explore in Prometheus (type http_).

Gotchas

OTLP defaults to gRPC :4317; for :4318 set OTEL_EXPORTER_OTLP_PROTOCOL=http/protobuf. Watch cardinality (auto-instr adds full URLs). Pin image versions beyond a lab.
