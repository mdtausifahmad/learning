# Core SRE curriculum delivered — shift to application & wisdom

The full planned 15-lesson arc (SLOs → alerting → observability → instrumentation → incidents →
postmortems → resilience → progressive delivery → toil/simplicity → NALSD) has been delivered — each
grounded in primary sources — with 16 reference sheets, a runnable lab, and a course index.

This resets the curriculum floor: future sessions should generally *not* introduce brand-new foundational
topics. Instead, calculate the zone of proximal development toward:

- **Application** — run the learner's *real* services, designs, and incidents through the methods (SLO
  drafts, NALSD reviews, postmortems). This is where a green operator becomes an operator, and it matches
  his stated "both judgment + practical application" driver.
- **Wisdom** — nudge toward a community (r/sre, CNCF Slack, SREcon) for real-world feedback; ask his
  preference first (still an open RESOURCES gap).
- **Retention** — spaced, interleaved retrieval of the SLO / alerting / resilience vocabulary to turn
  fluency into storage strength.

Optional deeper topics if he wants them: capacity planning, chaos engineering, multi-region / DR,
distributed-tracing internals, SLO tooling (e.g. Sloth), and the people-leadership side of SRE (Principal tier).
